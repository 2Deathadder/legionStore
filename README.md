# Legion Store

Application React + Tailwind pour le catalogue Lenovo Legion, les fiches produits, le panier persistant en session et les demandes de commande.

```bash
npm install
npm run dev
```

Les visuels actuels sont des placeholders Picsum, à remplacer par des visuels Lenovo autorisés. Firebase doit être configuré dans `src/firebase.js` avant la transmission réelle des demandes.
